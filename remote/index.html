📱 スマホ遠隔操作

接続と操作は、にゃーすけがGetscreen.me経由で行います。このページは、すぐ始めるための入口です。

Getscreen ダッシュボードを開く

始めるとき（亮介さんの手順は3つだけ）

  1. スマホで Getscreen Agent アプリを開いて、オンライン（緑の丸）にする
  2. にゃーすけとのチャットで「操作して」と言う
  3. 画面共有の許可が出たら「今すぐ開始」を押す

止めるとき

  • 通知パネルを開く → 画面共有の通知 →「停止」
  • 確実に止める：設定 → アプリ → Getscreen Agent →「強制停止」

接続先デバイス：Galaxy S25（SM-S931Z）。2026-11-14にフル操作の解放を確認済みです。このページをホーム画面に追加すると、次から1タップで開けます（ブラウザのメニュー →「ホーム画面に追加」）。
